# Gg-Browns

Sitio web oficial de **Gg Browns**, enfocado en servicios de micropigmentación y estética avanzada (microblading, nano brows, plasma fibroblast, entre otros).

## 🚀 Tecnologías utilizadas
* HTML5
* CSS
* JavaScript

## 📂 Estructura del proyecto
* `index.html` - Estructura principal del sitio.
* `estilos.css` - Hojas de estilo y diseño responsivo.
* `script.js` - Funcionalidad interactiva.
* `img/` - Imágenes del sitio.
